# Data Analytics Project

## Overview

This project demonstrates a complete end-to-end data analytics workflow using Python, SQL Server, Power BI, and Gamma AI. The objective of the project is to analyze customer shopping behavior data, clean and process the dataset, extract business insights using SQL queries, and visualize the findings through an interactive Power BI dashboard and presentation.

The project covers:

* Data loading and preprocessing
* Exploratory Data Analysis (EDA)
* Data cleaning and transformation
* SQL analysis using SQL Server
* Dashboard creation in Power BI
* Report and presentation preparation

---

## Dataset

The dataset contains customer shopping behavior information such as:

* Customer demographics
* Product categories
* Purchase amounts
* Review ratings
* Payment methods
* Discounts and subscriptions

The dataset was imported into Python for preprocessing and later stored in SQL Server for querying and analysis.

## Project Steps

### 1. Data Loading

* Imported CSV dataset using Pandas
* Checked dataset structure and data types

### 2. Exploratory Data Analysis (EDA)

* Analyzed missing values
* Checked distributions and trends
* Identified patterns and relationships in data

### 3. Data Cleaning

* Removed or handled null values
* Corrected inconsistent data
* Renamed columns for better readability
* Converted data types where necessary

### 4. SQL Analysis

* Imported cleaned data into SQL Server
* Executed SQL queries to generate business insights
* Used:

  * Aggregate functions
  * GROUP BY
  * ORDER BY
  * Subqueries
  * Filtering conditions

### 5. Power BI Dashboard

Created an interactive dashboard including:

* Sales analysis
* Customer insights
* Product performance
* Revenue trends
* Category-wise analysis

### 6. Reporting & Presentation

* Created a detailed analytics report
* Designed a professional presentation using Gamma AI
